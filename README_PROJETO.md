# Arandu NAPI Robótica (`arandu-napi-robotica`)

Sistema web da NAPI de Robótica (tema neon, módulos próprios, RAG em evolução).

- **Repositório Git:** esta pasta (`.git` aqui dentro)
- **Início rápido:** `Abrir_NAPI_Robotica.bat` ou `run_arandu.bat`
- **Documentação:** `docs/`, `COMO_USAR.md`
- **Projeto irmão:** `../gestao_editais_novo/` (Arandu PROPPG — Git separado)

Abra **somente esta pasta** no Cursor para trabalhar na Robótica.
