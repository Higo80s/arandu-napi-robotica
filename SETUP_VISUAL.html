⚠️ Troubleshooting Rápido

❌ PostgreSQL não inicia
→ Abra Services (services.msc) → postgresql → Start
❌ "could not connect to server"
→ Verifique credenciais em .env (user: gestao_user, pass: gestao_password)
❌ "pg_restore not found"
→ Instale PostgreSQL completo (inclui ferramentas)
❌ Dependências faltando
→ pip install -r requirements.txt
