Precisa de ajuda?

  3. Abra: SETUP_VISUAL.html (visual)
  4. Verifique: Mensagens de erro no console

Erros comuns:

  "could not connect to server"
    → Verifique credenciais em .env
    → Inicie PostgreSQL manualmente

  "pg_restore not found"
    → Instale PostgreSQL completo
    → Inclui ferramentas (pg_dump, pg_restore)

  "permission denied"
    → Execute como Administrador
    → Clique direito > Run as admin
