## 🔓 Opções para Dar Acesso à UTFPR

### **Opção 1: Tornar o Repositório Público (Recomendado)**

**Vantagens:**
- ✅ UTFPR pode acessar imediatamente
- ✅ Demonstra transparência e confiança no código
- ✅ Facilita compartilhamento do link
- ✅ Aumenta visibilidade profissional

**Como fazer:**
1. Acesse: https://github.com/Higo80s/gestao_editais
2. Clique em **Settings** (Configurações)
3. Role até o final da página
4. Em **Danger Zone**, clique em **Change repository visibility**
5. Selecione **Make public**
6. Digite o nome do repositório para confirmar
7. Clique em **I understand, make this repository public**

### **Opção 2: Adicionar Colaboradores Específicos**

Se quiser manter privado mas dar acesso à equipe UTFPR:

**Como fazer:**
1. Acesse: https://github.com/Higo80s/gestao_editais
2. Vá em **Settings** → **Collaborators and teams**
3. Clique em **Add people**
4. Digite o username GitHub da Patrícia ou colegas DIRGTI
5. Selecione permissão: **Read** (apenas leitura) ou **Write** (edição)
6. Envie o convite

**Problema:** Você precisa saber o username GitHub deles (pode não ter).

### **Opção 3: Criar Release Pública**

Manter repositório privado, mas criar uma "release" pública com o código e documentação:

**Como fazer:**
1. Acesse: https://github.com/Higo80s/gestao_editais
2. Vá em **Releases** (lado direito)
3. Clique em **Create a new release**
4. Tag: `v1.0-utfpr-submission`
5. Title: "Submissão UTFPR - Janeiro 2026"
6. Anexe arquivo ZIP do projeto
7. Marque como **public**
