Manual do Administrador - NAPI-Robótica / FUNTEF

Guia de Operação NAPI

Fluxos de trabalho integrados à base FUNTEF/CONVENIAR.

1. Gestão de Bolsistas

O sistema Arandú Napi-Robótica padroniza o ciclo de vida dos bolsistas conforme as diretrizes da FUNTEF:

  • Cadastro: Utilize o botão "Novo(a) Bolsista" no menu lateral. Certifique-se de que o CPF seja válido para evitar conflitos com a base do Sistema Acadêmico.
  • Vigências: O sistema monitora automaticamente o término das bolsas. Alertas de encerramento aparecem no Dashboard 30 dias antes do fim.
  • Monitoramento Mensal: Verifique a seção de Alertas para identificar bolsistas com previsão de defesa vencida.

2. Relatórios e Auditoria

Todas as exportações foram adaptadas para o ecossistema NAPI/FUNTEF:

  • Folha de Pagamento: Gere o Excel mensal para liquidação junto à FUNTEF. O cabeçalho já inclui a identificação do projeto.
  • ID Convênio: Os relatórios utilizam o campo "ID Convênio / FUNTEF" para rastreabilidade financeira, substituindo o antigo ID CAPES.
  • Auditoria Automática: O sistema realiza o cruzamento de dados entre a base local e o Sistema Acadêmico, sinalizando divergências de matrícula ou nome.

3. Segurança e Editor Visual

O Arandú utiliza o padrão Memento para garantir a integridade da interface:

"Cada alteração de texto realizada através do Editor Visual gera um Ponto de Restauração automático na tabela de Histórico (UIMementoHistory)."

Em caso de erro na edição de rótulos (ex: renomeação acidental), o Administrador Master pode reverter para o snapshot anterior através do console de gerenciamento.
