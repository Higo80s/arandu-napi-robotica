Arquitetura & Segurança
👋 Bem-vindo! Este guia rápido cobre as operações essenciais do dia a dia.
1. Workflow de Editais
  • Criar Edital: Inicie inserindo o número oficial e agência (ex: 01/2025).
  • Modalidades: Configure as regras de negócio (Valor, Duração Max, Vagas).
  • Vigência: O sistema bloqueará automaticamente datas que excedam a duração configurada.
2. Cadastro de Discentes

Ao inserir um novo bolsista:

  • Use a busca inteligente para encontrar o Programa.
  • O cálculo de término é automático baseada na data de início.
  • Atenção: CPFs duplicados serão rejeitados.
3. Importação em Massa

Suportamos carga de dados via Excel (.xlsx) e CSV.

Modelos suportados: Sucupira Principal, Fundação Araucária e Pós-Doc.

4. Dados Sociais & Coleta

O sistema agora coleta dados de identidade, trajetória e permanência.

  • Privacidade: Dados sensíveis protegidos.
  • Relatórios: Geração de estatísticas automáticas para o Plano de Permanência.
