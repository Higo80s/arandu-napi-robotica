Tutorial de Uso & Documentação

Bem-vindo ao Gestão de Editais v6.2

Este sistema foi desenvolvido para otimizar o gerenciamento de bolsas acadêmicas, garantindo integridade dos dados, cálculos automáticos de vigência e geração de relatórios precisos.

Novidade: Agora suportamos importação direta de arquivos Excel (.xlsx) e exclusão em massa!

Guia do Usuário

1. Gerenciando Editais

O Edital é a raiz de tudo. Em Editais > Novo Edital, cadastre:

  • Número e Agência: Ex: 01/2025 - CAPES.
  • Processo SEI: Para rastreamento administrativo.
  • Descrição do Projeto: Detalhes sobre o fomento.
2. Definindo Modalidades (Cotas)

Cada edital possui cotas específicas (Mestrado, Doutorado, IC). Após criar o edital, clique em Modalidades:

  • Valor Mensal: Define o custo financeiro.
  • Max Meses (Prazo): Crucial para o cálculo automático de vigência. Ex: 24 meses para Mestrado.
  • Vagas: Limite de bolsistas ativos simultâneos.
3. Cadastro de Bolsistas & Vigência

O coração do sistema. Ao cadastrar um bolsista:

  • Regime de Competência: O sistema calcula a data final baseado no Início do Curso + Duração da Modalidade.
  • Validação Rígida: Não é permitido cadastrar vigências que ultrapassem o limite legal do curso/edital (exceto Maternidade).
  • Afastamentos:
    • Saúde/Trancamento: Pausa o pagamento (suspensão).
    • Maternidade: Estende o prazo final em até 6 meses.
4. Importação em Massa (Excel/CSV)

Ideal para migração de dados ou cargas iniciais da Plataforma Sucupira.

  • Acesse Bolsistas > Importar.
  • Suporta arquivos .csv e .xlsx (Excel).
  • Tipos de Importação:
    • Padrão (CAPES DS): Requer colunas 'Tipo Vínculo', 'Modalidade', 'Beneficiário', 'Vigência'.
    • FA (Fundação Araucária): Importação específica para planilhas da FA.
    • PosDoc (Pós-Doutorado): Novo formato. Requer colunas: 'SEI', 'Residente', 'Programa', 'Campus', 'Projeto', 'Bolsa (sim/não)'.
  • O sistema detecta duplicatas e valida os dados automaticamente.

Boas Práticas

  • Backups: Utilize o script Agendar_Backup_ADMIN.bat para garantir cópias diárias do banco de dados.
  • Padronização: Use CAIXA ALTA para nomes e siglas (o sistema tenta converter, mas ajuda manter o padrão).
  • Revisão Mensal: Gere o Relatório em Excel todo dia 20 para conferir a folha de pagamento antes do envio.

Área Técnica (Para Nerds & Admins)

Stack Tecnológica:

  • Backend: Python 3.12 + Flask + SQLAlchemy.
  • Database: SQLite (Arquivo: instance/gestao_editais_new.db).
  • Frontend: Jinja2 Templates + CSS Variables (Temas Claro/Escuro/UTFPR).
  • Servidor: Waitress (Produção WSGI) na porta 5003.

Estrutura de Arquivos:

  • app.py: Lógica principal e rotas.
  • models.py: Definição das tabelas do banco.
  • reports.py: Motor de geração de PDFs e Excel.
  • scripts/: Automações de backup e manutenção.

Bug Conhecido: O atalho do Windows pode falhar se o caminho da pasta for alterado. Use Criar_Atalho.ps1 para regenerar.
