════════════════════════════════════════════════════════════════════════════════
                        ❓ TROUBLESHOOTING RÁPIDO
════════════════════════════════════════════════════════════════════════════════

PROBLEMA: PostgreSQL não inicia
  SOLUÇÃO: 
    1. Abra Services (services.msc)
    2. Procure por "postgresql"
    3. Clique direito → Start
    4. Ou: net start postgresql-x64-17

PROBLEMA: "could not connect to server"
  SOLUÇÃO:
    1. Verifique credenciais em .env
    2. Confirme user = gestao_user
    3. Confirme password = gestao_password
    4. Teste: psql -h localhost -U gestao_user

PROBLEMA: "pg_restore not found"
  SOLUÇÃO:
    1. Instale PostgreSQL completo (inclui ferramentas)
    2. Adicione ao PATH: C:\Program Files\PostgreSQL\17\bin
    3. Ou edite restore_backup_postgres.py com caminho correto

PROBLEMA: Dependências faltando
  SOLUÇÃO: pip install -r requirements.txt

PROBLEMA: Erro de permissão
  SOLUÇÃO: Execute como Administrador (clique direito > Run as admin)
